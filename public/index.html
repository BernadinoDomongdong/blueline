    How to use Blueline

    1. Get lineage onto the canvas

    Two ways to start: paste or upload SQL, DAX, or Power Query (M) in the Sources panel on the left and click Infer lineage — parsed locally, no AI, no API key. Or click ▶ Load demo on the empty canvas to see a worked example first.

    2. Build or edit it by hand

    Turn on ✎ Edit diagram to reveal the editing tools:

    • Palette (top-left of the canvas) — drag a Table, View, Column, or Measure onto the canvas to drop it exactly there, or click a chip to add one at the center of the current view.
    • + Node / + Edge — add either through a form instead, if you'd rather type it in directly.
    • ⇄ Connect — drag from one node straight to another to link them. A small handle appears on hover; drag from that handle to the target node.
    • Double-click any node or edge to edit its details, or select it and press Delete to remove it — every delete offers a one-tap Undo.

    3. Read the diagram

    A solid line means high-confidence lineage (resolved from a real SQL parse, or entered by hand). A dashed line means medium or low confidence (DAX/M pattern-matching, or an ambiguous unqualified column) — worth a second look. Click any node to see exactly what feeds it and what it feeds, in the Inspect tab.

    4. Ask questions and generate reports (optional)

    The Ask AI and Reports tabs are grounded in whatever graph is currently on the canvas. They need an AI provider configured — click AI: Off in the header to bring your own API key (Anthropic, OpenRouter, or your own custom endpoint), stored only in your browser and used only for your own requests. Without one set up, both tabs say so plainly and the rest of the app is unaffected.

    5. Save your work

    Use the canvas toolbar to Export JSON (round-trips back in later, or hand off to a teammate — preserves your manual layout), Export CSV (the edge list, for a spreadsheet), Export PNG (a snapshot), or Import JSON to load a saved graph back in.

    AI settings

    Powers the optional Ask AI and Reports tabs only — lineage extraction never uses AI. Stored in this browser only (never on a server); sent straight to the provider you pick, per request, and nowhere else.
